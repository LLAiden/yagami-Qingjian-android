# Android 0.2.4 布局与模式验收

日期：2026-10-03。版本：0.2.4-preview / versionCode 11。需求见 [已确认产品范围](../plan/android-product-optimization.md)。

## 本轮修改

- 页面从上到下为候选区、剪贴板栏、编辑菜单、输入区。没有正在输入的拼音时隐藏候选；英语与数字页不显示候选。
- 剪贴板、编辑、全选、收起按钮仅显示图标，以固定 48dp 宽度靠右排列，辅助功能名称保留。
- Android 输入模式精简为拼音九键、英语全键盘、数字九键；中文全拼切换移除，旧方案偏好不影响布局。
- 所有模式统一英文半角标点，符号页提供两组 ASCII 符号，返回原键盘。
- 切换数字页先提交拼音；保留英语释义、鼻音、宽退格、最右下角动作及之前的输入修复。

## 自查与复查

修改前在 0.2.3 上运行最初的四项需求用例，四项均失败：空闲候选可见、页面顺序不符、中文全拼入口仍在、转数字未提交拼音。

首次改为直接改变窗口高度后，实际触摸回放发现候选显隐时窗口与输入坐标短暂不同步：输入下一键会误触空格，提前提交“哦”等候选。辅助功能缓存清理不足以解决，未以等待更久掩盖问题。
最终固定 IME 窗口测量高度，以透明顶部和实际内容 / 触摸 insets 隐藏空闲候选区域、归还宿主显示与操作空间。按键保持屏幕位置，连续触摸不因窗口变高而错位。

新增 `KeyboardLayoutTest` 七项全部通过，用时 28.079 秒：

1. 空闲候选隐藏，输入和选词后按键屏幕坐标不变。
2. 候选、剪贴板、编辑菜单、输入区按指定顺序排列，英译可见。
3. 拼音九键 → 英语全键盘 → 数字九键 → 英语 → 拼音，结果逐字一致。
4. 输入 `64426` 转数字先得到“你好”，返回仍为拼音九键。
5. 菜单只有图标，48dp 固定点击宽度、靠右布局。
6. 中文、英文、数字切换过程中英文标点逐字一致。
7. 使用输入前的固定按键坐标，连续十次输入 `64426` 并选词，最终恰为十次“你好”。

## 环境与验证范围

自动化环境为 Android 15 / API 35 ARM64 模拟器，Pixel 6，1080×2400，密度 2.625，在真实系统 IME 窗口注入触摸事件。
JNI 两项测试、fmt 和 JNI clippy 通过；Core 输入算法本轮未修改，沿用 0.2.3 的 313 项通过记录。双 ABI JNI 重建，Debug、AndroidTest、未签名 Release 构建成功，lint 无错误（Debug 16 / Release 14 条既有警告）。

全量 Android 回归 60 项通过，用时 257.507 秒：已有 53 项随三种模式调整使用步骤，加本轮 7 项布局回归。快速 / 双指 / 输入框重启共 1,320 个数字逐字一致，数字模式的同输入框重启仍能保留按下中的按键。

小米 25053RT47C / Android 16 已成功从 0.2.3 覆盖安装到 0.2.4，读取包信息确认 versionCode 11；预览输入法已启用并选中，输入验收页已打开，系统显示 `mInputShown=true`、`mImeWindowVis=3`。预览签名沿用上一版本。真实应用手动体验由用户继续进行。

厂商手机安装成功不代表微信、QQ、大字体、TalkBack 或 Android 8 的兼容性已验收；本轮不创建上游行为 PR、不发布为稳定版。
