# Yagami Android 1.0.0 验收记录

日期：2026-10-03。versionName 1.0.0，versionCode 15。保留用户确认的三模式、固定顶栏、左侧拼音组合、工具排序和底行位置。

## 数据与学习边界

未新增预制词库或语言模型。Android 仍复制原有 `assets/lexicon/dict.tsv` 与 `assets/glossary/glossary-en.tsv`，评测文件不进入 APK。
个人词句仅从明确点击候选建立，自动结束、空格、换行与模式切换不强化默认答案。最多 4096 条聚合记录；最近纠正优先。
重复的分段选择可建立个人词句，测试通过真实引擎选择“米”与“猫”，重建后得到“米猫”，锁定不符读音后不再召回。
记录只含输入编码、汉字词句、音节、次数与逻辑顺序；不装配输入日志、统计、云预测或用户正文采集。
关闭学习或私密输入时不读取个人排序、不写新数据；清除恢复基础排序。英文直输、数字、邮箱与网址不学习。

学习存储与剪贴板使用 AES-256-GCM，密钥由 Android Keystore 保存且不可导出。AAD 绑定包名、存储实例与槽位，验证损坏 / 替换失败后不回退明文。
学习保存等待输入停顿 600ms，随后在后台加密；学习存储失败不阻止基本输入。未固定历史 24 小时过期，最多 30 条，固定条目不按时间过期。
剪贴板敏感标记、4–8 位纯数字及 13–19 位长数字串不进历史，敏感当前复制遮蔽预览但可明确点击粘贴。
清除历史保留系统当前复制并抑制同一次复制再次入库。关闭历史会删除旧历史，新复制也不再入库。
本地数据丢失或密钥不可用时不写明文；旧明文历史无法加密则删除旧槽位。

Android 关于 [Keystore](https://developer.android.com/privacy-and-security/keystore)、[加密算法](https://developer.android.com/privacy-and-security/cryptography)、
[私密输入声明](https://developer.android.com/reference/android/view/inputmethod/EditorInfo#IME_FLAG_NO_PERSONALIZED_LEARNING) 与
[备份规则](https://developer.android.com/identity/data/autobackup) 为实现边界的依据。宿主没有正确声明的敏感内容仍需用户手动关闭学习 / 历史。

## 算法与准确性

- Core 313 项、learning 24 项、JNI 9 项通过；JNI 覆盖候选 / 释义、分段提交、恢复、私密 / 禁用、清除、长整句、自动提交不学习和实际造词。
- CLI 使用产品基础词库验证九键查询；Rust fmt、JNI / learning / CLI clippy 通过。
- 冻结 50 条合成日常词句，经过产品 Android 候选路径和 60 项展示截断：首选 47/50，前五 50/50，展示覆盖 50/50。
- 非首选为“收到”（首选“受到”）、“密码”（首选“你吗”）、“我喜欢编程”（首选“我喜欢变成”）。整句手动选词后成为第一项的回归通过。
- 该小样本是回归基准，不是随机抽样，也不是任意文本的总体准确率；没有为样例添加基础词语或权重。
