# Android 0.2.3 界面、输入与存储验收

日期：2026-10-03。安装包：`0.2.3-preview`，versionCode 10。本轮接续 [十轮自查](android-ten-round-audit.md)，处理用户随后反馈的界面、释义、卡顿、快速输入、存储、鼻音与动作键问题。

## 验证环境与结果边界

- Android 15 / API 35 ARM64 模拟器，Pixel 6 配置，1080×2400，密度 2.625；真实系统 IME 窗口注入触摸，使用随包产品词库与英语释义。
- Debug 与未签名 Release 均构建；Rust JNI 同时编译 `arm64-v8a`、`x86_64`；MMKV 两种 ABI 和许可随 APK 打包。
- Core 全量 313 项、JNI 2 项通过；fmt、Core / JNI / CLI clippy 通过；CLI 使用产品词库回放九键查询。
- Android 交互回归包含旧 38 项、界面 6 项、性能 2 项、快速输入 4 项、鼻音 2 项、存储迁移 1 项，共 53 项，最终全量通过，用时 226.277 秒；原始日志随交付包提供。
- Android lint 无错误，Debug 16 条、Release 14 条警告，主要为代码创建 View 的构造器、固定 UI 文字、资源、目标 SDK，以及调试页静态引用；迁移旧 SP 的同步清理是有意保留。

小米 25053RT47C / Android 16 此前拒绝 USB 安装（`INSTALL_FAILED_USER_RESTRICTED`），没有完成预览版真机验收。本次不会将模拟器成绩写成该手机、微信、QQ、厂商系统或 Android 8 的测试结果。

## 性能测量

`KeyboardPerformanceTest` 使用产品 JNI，20 次预热后采样 80 次相同输入变化。
分别测量 native snapshot + JSON，以及 View 更新、测量、布局和软件 Bitmap 绘制；测量对象为未挂载的原生键盘 View。
单位为毫秒。同一模拟器上的优化前 / 后记录如下：

| 段 | 优化前 P50 / P95 | 优化后 P50 / P95 |
|---|---|---|
| native + JSON | 0.231 / 0.546 | 0.249 / 0.666 |
| 候选更新 + 布局 + 软件绘制 | 8.425 / 10.606 | 2.514 / 2.982 |

界面段 P95 下降约 72%；主要收益来自减少候选与样式构建、复用视图。这里没有证明 native 段变快，也不是触摸到屏幕呈现的端到端指标。
测试不包含宿主应用耗时、系统合成帧、冷启动或真实低端手机，因此不能写成“整机输入快 3 倍”或“已消除所有卡顿”。
完整基线与复测日志随交付包提供，后续性能需求见 [产品计划 R03](../plan/android-product-optimization.md)。

## 交付与限制

预览版与原版并存，可覆盖升级同签名的 0.2.0–0.2.2 预览包。对应源码、累计补丁、测试日志、许可、APK 校验值与证书信息一起交付。
单元测试验证了旧 SP 的迁移和重开；厂商真机连续跨版本安装仍是后续验收项。

三组鼻音以外的模糊设置、九键简拼、用户词频持久化、语音和滑动输入尚未接入 Android。
每词最多 64 个九键别名记录，极长词的所有多音节模糊组合不保证穷举。
英语释义受随包数据覆盖率限制；长按使用系统 Toast，长内容受行数限制，常驻可滚动详情仍列为后续需求。
极窄屏、大字体、TalkBack、折叠屏以及真实应用兼容矩阵尚需专项验收。

没有创建上游行为修改 PR，也没有发布为稳定版；仓库要求行为 PR 真机验收，当前保留在用户 fork 预览分支。
