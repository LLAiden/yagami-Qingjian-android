# Android 十轮自查与体验优化

日期：2026-10-03。起点：0.2.1-preview，`c0e9a3f`。每轮依次进行自查、修改、针对性再自查，最终执行完整验收。
交互测试使用 Android 15 ARM64 模拟器的真实 IME 窗口和 InputConnection。厂商手机与真实微信、QQ 的验证另行记录。

| 轮次 | 自查发现 | 修复或优化 | 再自查 |
|---|---|---|---|
| 1 | 展开候选的刷新会重建删除键，长按只删除一次；新增复现测试失败 | 候选内容单独刷新，保留删除键及长按任务 | 展开候选长按退格与选词返回两项通过 |
| 2 | 读取同一剪贴板会刷新保存时间，24 小时保留期被不断延长；复现测试失败 | 使用系统实际复制时间，重复读取不续期，重新复制仍更新 | 时间保留与面板去重两项通过 |
| 3 | 私密复制的拦截仅在内存中，重建后同次复制进入历史；复现测试失败。复查另发现旧实例会重新写回已清空的历史 | 仅持久化复制事件时间戳；原子读取内容与标记；修改前同步历史快照，过期清理落盘 | 重建拦截、正常新复制恢复、密码框历史及复制时间三项通过 |
| 4 | 电话框无动作时显示无效换行；应用自定义 actionLabel/actionId 未执行；两项复现失败 | 数字类无动作回退完成并收起；支持自定义动作及上一项标签 | 电话完成、自定义动作、原有换行与完成三项通过 |
| 5 | 顶栏仅能全选，复制、剪切与光标定位需要依赖宿主菜单 | 增加编辑面板，操作前提交组句，使用宿主标准复制、剪切、粘贴和导航动作 | 实际复制 / 剪切 / 粘贴 / 光标后输入与原有选区删除两项通过 |

| 6 | 固定高度无法调整，设置重建需要保留导航安全区和数字页 | 增加矮 / 标准 / 高三档，保存偏好，刷新时沿用安全区并恢复数字布局 | 高度变化、重开保持、数字页保持及小数剪贴板三项通过 |

| 7 | 键盘固定浅色，夜间使用亮度和对比度不合适 | 默认跟随系统，可选择浅色 / 深色并保存；面板文字和导航栏同步配色 | 截图像素验证实际颜色、重开保持、选词、高度与展开候选三项通过 |

| 8 | 手指滑出删除键后仍连续删除，复现 300 毫秒额外删除 4 字符 | 滑出触摸容差区取消删除任务，松手不再补发删除 | 滑出取消、普通长按松手、展开候选长按三项通过 |

| 9 | 拼音达到 64 个按键后静默拒绝新输入，缺少反馈 | 增加可见上限说明和节流提示，保留原输入，选词或删除后可继续 | 64 键达到上限、超限保持、删除后恢复和快速输入收起两项通过 |

| 10 | 同一输入框 restartInput 先移除 composing 标记，导致候选被清掉；保持组句的复现失败 | 延迟确认 composing 结束，仅在类型、隐私属性和光标前文字一致时恢复；正文改变则丢弃旧组句 | 同类型继续选词、正文替换、隐私 / 数字属性刷新、原有密码历史和选区删除五项通过 |

## 完整验收与交付

- 版本：0.2.2-preview / versionCode 9，独立预览包名不变；与 0.2.1 使用同一预览签名，可直接覆盖升级。
- Android 15 ARM64 Pixel 6 模拟器：38 项真实 IME 交互验收全部通过，包含原有 23 项和新增 15 项，完整运行 120.069 秒。
- Core 311 项、Android JNI 2 项测试通过；Rust fmt 和 JNI / CLI clippy 通过。
- arm64-v8a 与 x86_64 native Release 构建通过；Gradle Debug / Release 构建、两种模式 lint 与 AndroidTest 构建通过。
- APK 签名验证通过（v2）；minSdk 26、targetSdk 35，包内包含上述两种 64 位架构。
- 另验证默认跟随系统主题：切换系统夜间模式后实际按键颜色更新，恢复浅色后仍可正常选词。

全部十轮保留修改前的失败记录与修改后的通过记录，交付目录同时提供完整运行日志、APK、对应完整源码、累计补丁和 SHA-256 校验值。

- 已连接 Android 16 小米手机（型号 25053RT47C），USB 安装被系统拒绝，错误为 `INSTALL_FAILED_USER_RESTRICTED`。未完成真机验收，原默认输入法已恢复。
- 厂商真机、真实微信 / QQ、Android 8–14 的应用兼容性仍需验证；支持版本和实际验证版本分别记录。
- lint 没有错误；Debug 有 11 条、Release 有 9 条警告，涉及目标版本提示、调试页静态引用、未使用资源、仅程序创建的 View 构造器与文本国际化提示。
- 当前仍不提供滑动输入、语音输入和用户词频持久化。此轮未更换词库或数据许可。
