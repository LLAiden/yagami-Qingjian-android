# Android 布局与输入模式需求

日期：2026-10-03。本轮以用户明确的四项需求及同栏补充为准，最终版本为 0.2.5-preview。

## 已确认范围

| 需求 | 行为与验收 |
|---|---|
| 页面顺序 | 从上到下为候选词语、工具栏、输入区域；用户补充确认剪贴板与编辑 / 全选必须在同一栏；没有正在输入的拼音时隐藏候选区；显示候选时不能移动按键或中断触摸 |
| 三种输入模式 | 仅拼音九键、英语全键盘、数字九键；移除中文全拼切换；英语直接输入字母，数字直接输入数字；转数字时先提交当前拼音 |
| 菜单精简 | 剪贴板、编辑、全选、收起合并在同一栏，只显示图标，固定按钮宽度、靠右排列，不把按钮均分拉满屏幕；图标保留中文辅助功能名称和点击范围 |
| 英文标点 | 用户确认各模式均可使用标点，但统一为英文半角；符号页只包含英文符号，用完可返回之前的键盘 |

符号页是临时工具面板，不增加第四种输入模式。剪贴板、编辑、设置和展开候选也沿用临时面板。

## 保留的使用能力

保留英语释义、独立拼音消歧、鼻音开关、最右下角搜索 / 换行 / 发送动作、宽退格键、居中九宫格、全选删除、剪贴板历史、收起入口、主题与高度、导航安全区域，以及快速输入回归。

## 交付与验收

按“自查 → 修改 → 复查”完成：先在原布局上确认需求用例失败，再检查新布局的页面顺序、候选显隐、图标边界、模式切换和英文标点，最后运行现有输入回归。

安装包使用 versionCode 12，签名沿用之前的预览包，可覆盖升级 0.2.0–0.2.4。模拟器自动化结果与真机安装状态分开记录，不能把安装成功写成微信等应用兼容性验证通过。

本轮结果见 [布局验收](../notes/android-layout-validation.md)。先前的大范围产品建议不再作为当前待实现需求。
