# Android 布局与常用工具需求

日期：2026-10-03。本轮以用户明确的布局与工具补充为准，最终版本为 0.2.7-preview。

## 已确认范围

| 需求 | 行为与验收 |
|---|---|
| 顶部共享一行 | 用户最终确认空闲显示工具、输入时原位显示候选与英译，只保留收起工具按钮；不增加高度或移动按键；剪贴板与编辑 / 全选仍在同一工具栏 |
| 拼音组合 | 输入时左侧独立滚动栏显示九键的多种拼音组合；空闲显示常用英文标点 |
| 输入区整理 | 语言切换集中底行，去除重复工具和模式入口；符号分页明确显示方向；回车与其他按键间距一致 |
| 三种输入模式 | 仅拼音九键、英语全键盘、数字九键；移除中文全拼切换；英语直接输入字母，数字直接输入数字；转数字时先提交当前拼音 |
| 菜单精简与顺序 | 同栏从左到右为全选、编辑、Google 验证器、Bitwarden 密码管理器、剪贴板、收起；只显示图标，固定按钮宽度、靠右排列，不把按钮均分拉满屏幕；图标保留中文辅助功能名称和点击范围 |
| 英文标点 | 用户确认各模式均可使用标点，但统一为英文半角；符号页只包含英文符号，用完可返回之前的键盘 |
| 拼音空格 | 空格只占中央一个键位；同一行左侧为 `123` 切数字，右侧为 `EN` 切英语全键盘，三键等宽；动作键仍在最右下角 |
| 英语空格与大小写 | 空格在键盘中线，左侧紧邻 `123`，右侧紧邻 `中文`；Shift 一次单字母大写、两次锁定后续大写、再次解除，锁定有不同图标状态 |
| 数字底行 | 中央三列为 `EN | 0 | 拼音`，0 居中、与 2 / 5 / 8 对齐；空格在左侧功能列，小数与电话符号保留 |
| 密码与双因素入口 | 同栏添加 Bitwarden 与 Google 验证器启动按钮，使用已安装应用；未安装或无法打开时有提示，不丢失输入 |
| 圆形图标底 | 同栏六个 18dp 图标都在圆形底中心；点击范围固定 48dp，36dp 圆底适配浅色 / 深色与按下状态 |

符号页是临时工具面板，不增加第四种输入模式。剪贴板、编辑、设置和展开候选也沿用临时面板。

## 保留的使用能力

保留英语释义、独立拼音消歧、鼻音开关、最右下角搜索 / 换行 / 发送动作、宽退格键、居中九宫格、全选删除、剪贴板历史、收起入口、主题与高度、导航安全区域，以及快速输入回归。

## 交付与验收

按“自查 → 修改 → 复查”完成：先在原布局上确认需求用例失败，再检查新布局的页面顺序、候选显隐、图标边界、模式切换和英文标点，最后运行现有输入回归。

最终安装包使用 versionCode 14，签名沿用之前的预览包，可覆盖升级此前预览包，包含 versionCode 13 的 0.2.6 体验包。模拟器自动化结果与真机安装状态分开记录，不能把安装成功写成微信等应用兼容性验证通过。

本轮结果见 [布局验收](../notes/android-layout-validation.md)。先前的大范围产品建议不再作为当前待实现需求。
