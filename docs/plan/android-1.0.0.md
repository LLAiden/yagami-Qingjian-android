# Yagami Android 1.0.0 交付目标

日期：2026-10-03。延续用户已确认的交互，目标为日常可用、离线、注重隐私的输入法。

## 产品边界

- 仅拼音九键、英语全键盘、数字九键；统一英文标点，语言切换与空格 / 0 的位置按用户最终确认。
- 顶栏固定高度，空闲显示六个圆底工具图标，输入时原位显示候选和英译，仅保留收起；左侧滚动展示拼音组合。
- 维持快速输入不漏字、选择与退格准确、最右下角宿主动作、导航安全区域和横屏。
- 不新增预制词库；保留项目原有的拼音转换基础数据，个人词句只从实际选词逐步建立。个人选词偏好仅在本机加密保存，帮助同码词排序；可以关闭学习、清除数据。密码、验证码与应用声明的私密输入不学习。
- 个性化只作辅助：有界索引读取，最多 4096 条；连续输入期间不序列化整个快照，停顿后后台加密写入。基本输入不依赖学习存储成功。
- 剪贴板历史加密保存，保留固定、去重和过期能力；敏感复制仅即时粘贴，隐藏敏感内容预览；历史记录可关闭。
- 正式安装包无网络权限、无输入日志、无广告与分析 SDK、无调试输入页、关闭调试能力；禁用云备份与设备迁移。

## 验收与交付

算法以冻结的日常词句样例衡量候选覆盖和首选，另测歧义选词学习、关闭与清除、跨重建恢复、私密隔离和鼻音。样例结果不能表述为所有输入的准确率。
Android 回归覆盖既有布局、快速 / 双指 / 重启输入、编辑动作、剪贴板与私密输入；增加加密迁移和密文损坏、学习持久化、正式包清单与签名检查。
签名升级先在模拟器验证；按用户最新要求，真机留作最终体验。保留设置与历史，交付 APK、源码、许可、校验值、测试报告、使用与隐私说明。
真实应用 / TalkBack / 最低 Android 版本未验证的范围如实记录。不开设没有证据支持的“全场景稳定”或“100% 预测准确”承诺。
