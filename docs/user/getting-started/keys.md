桌面平台功能相同，按键按各自系统的习惯设计。表中 `⌥` 为 Option，`⌘` 为 Command，`⌃` 为 Control，`⇧` 为 Shift；
「—」表示该平台没有此键。

## 切换模式

| 操作 | macOS | Windows |
|---|---|---|
| 中 / 英切换 | `Caps Lock` | 单击 `Shift`（设置里还可勾单击 `Ctrl`、`Ctrl + Alt + Space`，可多选）；系统的 `Ctrl + Space`；或点击任务栏 / 悬浮状态条上的「中 / 英」 |
| 直接输入大写英文 | 英文模式下按住 `⇧` | `Caps Lock` 亮起（中英模式均可） |
| 输入拼音时临时输入一个大写字母 | `⇧ + 字母`：拼音原样上屏，再输入该大写字母；设置里可改成「进组句」：大写按小写参与匹配，`Cpan` 与 `cpan` 一样能出「C盘」 | 同左 |
| 切换全角 / 半角标点 | 中文全角、英文半角，不可更改 | 点击悬浮状态条上的「，。」格，中英各记一份 |
| 切换到其他输入法 | `⌃ + Space`（系统） | `Win + Space`（系统） |

Windows 的「中 / 英切换」键在设置里勾选，可以多选：单击 `Shift`、单击 `Ctrl`（打字时容易误触 `Shift` 的话）、`Ctrl + Alt + Space`；一个都不勾就只剩按钮能切。中英模式所有应用共用一份。关掉「内置英文模式」后，切换键与任务栏、悬浮状态条上的「中」「英」都不再切到英文，需要英文时用 `Win + Space` 切到别的输入法。

Windows 的主键盘数字和常用标点按当前系统键盘布局识别；非美式布局的字母、AltGr 和组合音符输入仍有局限。

Windows 上中 / 英的切换键可以勾选（设置 → 通用，配置 `[shortcut] switch_mode`，可多选）：**单击 Shift**（缺省，与微软拼音一致）、
**单击 Ctrl**（Shift 老是误触时用）、**Ctrl + Alt + Space**（组合键，最不易误触）；一个都不勾就只剩任务栏 / 悬浮状态条上的「中」「英」按钮能切。
改完**立刻生效**；没在打字时 Shift 在其他组合键里的作用不受影响。系统自带的 `Ctrl + Space`（输入法/非输入法切换）也能切中英，与微软拼音一致，不在勾选项里。

还可以整个关掉**内置英文模式**（设置 → 通用，配置 `[general] english_mode`）：关掉后青简固定中文模式，
切换键与任务栏、悬浮状态条上的按钮都不再切到英文，需要英文时用 `Win + Space` 切到别的输入法。
详见 [英文模式](../input/english-mode.md)。

## 输入组句时（拼音 / 注音 / 五笔）

| 操作 | macOS | Windows |
|---|---|---|
| 上屏高亮候选（无候选时上屏所敲的拼音 / 注音 / 编码） | `Space` | `Space` |
| 上屏当前页第 N 个 | `1` 至 `9` | `1` 至 `9` |
| 将敲的字母 / 注音符号原样上屏 | `Enter` | `Enter` |
| 删除光标前一个字母 / 注音 / 编码 | `Backspace` | `Backspace` |
| 删除光标后一个字母 | `Delete` | — |
| 删除光标前一个音节（五笔下是整段编码，同左的「全部」） | `⌥ + Backspace` | — |
| 删除光标前全部拼音 | `⌘ + Backspace` | — |
| 清空 | `Esc`（打开「横排时 ↑ / ↓ 展开成多行」且矩阵展开着时，第一下先收回单行） | `Esc` |
| 清除辅码（保留拼音与候选） | `Esc` | `Esc` |
| 移动高亮（到页边自动翻页） | `↑` / `↓` | `↑` / `↓` |
| 横排展开成 6 行矩阵并换行（macOS，需先在「偏好设置 → 候选窗口」勾选「横排时 ↑ / ↓ 展开成多行」，缺省关） | `↑` / `↓`；`←` / `→` 在候选之间移动（单行、展开后都是），移出矩阵上下边缘时按行滚动 | — |
| 翻页 | `[` `]`、`PageUp` / `PageDown`、`⇧ + Tab`（上一页） | `[` `]`、`PageUp` / `PageDown`、`Shift + Tab`（上一页） |
| 进入辅码状态并输入码 | `;`（可改为其他单个可见字符），之后直接输入码字母 | 同左 |
| 接受云端整句补全 | `Tab`；无补全时翻页 | `Tab`；无补全时下一页 |
| 移动拼音光标 | `←` / `→`（打开横排展开开关后，横排下这两个键改为移动候选高亮，拼音光标用 `⌥ + ←` / `⌥ + →`） | `←` / `→` |
| 按音节移动光标 | `⌥ + ←` / `⌥ + →` | — |
| 光标移到开头 / 末尾 | `⌘ + ←` / `⌘ + →`，或 `Home` / `End` | `Home` / `End` |

光标停在中间时，候选只按光标之前的拼音计算（`ni|hao` 出 你）；上屏后其余拼音保留，光标移到末尾。
若前面某个音节输入有误，macOS 上可按 `⌥ + ←` 移到其后、`⌥ + Backspace` 删除后重输、`⌘ + →` 回到末尾。

### 注音模式（Windows）

「设置 → 通用」打开「大千注音」后，组句中的按键改为：

| 操作 | Windows |
|---|---|
| 上屏高亮候选 | `Enter` |
| 将注音符号原样上屏 | `Shift + Enter` |
| 一声 / 轻声 | `Space` |
| 声调与符号（进入组句，不选词） | 数字键，`-` `;` `,` `.` `/` |

大千键盘布局把数字键与 `- ; , . /` 都分给了注音符号和声调，所以注音模式下这些键不再选词，选词用 `Enter`；`Space` 是一声。macOS 暂无注音模式。

> **五笔（形码）**：组句时敲的是字根编码，没有音节的概念，所以「删到音节边界」「拼音行分段」这些不适用，
> 左右键按单个字母移动光标。整句输入、简拼、模糊音、拼写纠错在五笔下都不生效，
> `v` / `u` / `i` 也不再是模式键（它们是字根键）。选词、翻页、上屏、删除候选与拼音一致。
> 拼音方案与五笔**同时开着**是混输：两边都出候选、编码打全的五笔词在前，见 [模糊音与输入方案](../input/fuzzy-and-shuangpin.md)。

翻页键对可改为 `,` `.` 或 `-` `=`：「偏好设置 → 快捷键」。

## 英文模式下

| 操作 | macOS | Windows |
|---|---|---|
| 选择高亮候选 | `Space`、`Tab` | `Space`、`Tab` |
| 选择第 N 个候选（当前页没有第 N 个时，数字作为内容接在所敲字母后，如 `gpt6`） | 数字键 | 数字键 |
| 移动高亮 / 翻页 | `↑` / `↓`、翻页键 | `↑` / `↓`、翻页键 |
| 原样输出所敲字母 | `Enter`、标点 | 同左 |

没有候选时数字直接接在字母后（`xq1`）；带数字的标识符先按 `Enter` 输出字母再敲数字。

## 译词与删除候选

| 操作 | macOS | Windows |
|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 数字` | `Ctrl + 数字` |
| 上屏第二条译词（候选右侧有两条时） | `⇧⌥ + 数字` | `Ctrl + Shift + 数字` |
| 删除第 N 个候选 | `⇧ + 数字` | `Shift + 数字` |

仅在输入拼音时有效。三组修饰键在「偏好设置 → 快捷键」（Windows：「设置 → 快捷键」）录制修改；
macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页），Windows 上 `Alt + 数字` 会被应用作为菜单快捷键截获。
删除候选的说明见 [译词与生词](../learning/translation.md#删除不需要的候选)。

## 云联想

| 操作 | macOS | Windows |
|---|---|---|
| 翻译应用中选中的文字 | `⌃⌥T` | `Ctrl + Alt + T` |
| 翻译结果：替换选区 | `Enter` / `Space` / `1` | 同左 |
| 翻译结果：保留原文 | `Esc` | `Esc` |
| 问字 | 输入 `u`（双拼下 `Shift`+`U`）再输入拼音；勾选「敲 ? 也进入问字」后未输入拼音时输入 `?` 再接拼音同样可用 | 同左 |

均需先打开云联想，见 [问字与翻译](../cloud/question-and-translate.md)。翻译快捷键可修改；Windows 上修改后需切换到其他输入法再切回青简才生效。

## 前缀键

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 时间 / 星期 |
| `v` + 算式或数字 | 算式结果、中文数字与金额（`v123.5` → 壹佰贰拾叁元伍角）；双拼下以 `Shift`+`V` 开头 |
| `u` + 十六进制 | 该码点对应的字符；双拼下以 `Shift`+`U` 开头 |
| `u` + 拼音 | 问字（需打开云联想）；`?` + 拼音需在「快捷键」页勾选后可用 |

两个平台相同，详见 [快捷输入](../input/shortcuts.md)。`v` 与 `u` 可在「快捷键」页改为 v、u、i 三者之一。

## Linux（Fcitx5）

单击 `Shift` 切换中英；按住 `Shift` 输入字母不会切换。`Space`、`1` 至 `9` 以及候选点击选词，
全拼 / 双拼下 `Enter` 原样输出，`Backspace` / `Delete` 编辑，`Esc` 取消，方向键移动高亮或光标。
`[` / `]` 和 `PageUp` / `PageDown` 翻页；翻页键可在配置文件修改。

Linux 的 `Tab` 规则：没有组句时 `Tab` / `Shift + Tab` 交给应用；中文组句中 `Tab` 接受整句补全，
无补全时下一页；英文组句中 `Tab` 选择高亮候选；组句中的 `Shift + Tab` 始终上一页。
Linux 当前提供本地候选，尚无云端整句补全。裸问号的既有还原规则优先。

数字选择当前页对应候选；当前页没有这一格时数字接入缓冲区，`hao6` 回车可原样输出。
进入英文直输段后数字和标点继续追加，`gpt-6` 后按空格得到 `gpt-6 `。
英文候选开启时，数字、翻页键和空格同样可选词，空格选词后保留一个空格。
小键盘运算符保持半角；关闭 NumLock 时按导航键处理。

`[general] shift_letter = "compose"` 可让大写字母参与中文组句，默认原样输入大写英文。
双拼下 `Shift + V` / `Shift + U` 分别进入表达式 / 码点输入，入口字母可在 `[shortcut]` 修改；问字的云服务暂未提供。
大千注音（`[general] scheme = "zhuyin"`）下，数字及 `- ; , . /` 输入符号和声调，空格补一声，再按空格可选词；
`Enter` 选高亮，`Shift + Enter` 原样输出注音。

Linux 缺省 `Alt + 数字` / `Alt + Shift + 数字` 上屏第一 / 第二条译词，`Shift + 数字` 删除候选，
可在配置文件 `[shortcut]` 修改。安装与配置位置见 [Linux](linux.md)。

## Android

Android 版使用屏幕软键盘，当前按键如下：

| 操作 | 按键 |
|---|---|
| 九键拼音 | `2`–`9`；例如 `64426` 输入“你好” |
| 九键的 1 键 | 打开符号页；数字页的 `1` 则直接输入数字 |
| 消除九键同码歧义 | 点击候选栏下方的拼音，例如 `ni` 或 `mi` |
| 上屏第一候选 | `空格` |
| 上屏指定候选 | 点击候选 |
| 展开候选 | 候选栏右侧省略号打开多列列表，上下滑动后点击选词；`返回键盘` 收回 |
| 查看英语释义 | 候选下方直接显示；长按候选查看释义提示；点选候选仍只输入中文 |
| 换行或执行输入框动作 | 最右下角动作键：先提交正在输入的第一候选，再换行，或执行应用要求的发送、搜索、完成等动作 |
| 应用自定义动作 | 回车键显示并执行应用指定动作；无指定动作的数字或电话输入框显示 `完成` 并收起键盘 |
| 删除文字 | 有选中文字时删除整个选区；否则删一个拼音键或一个完整字符，长按连续删除 |
| 临时输入一个大写字母 | 向上箭头 Shift 图标后点击字母；高亮表示当前已开启 |
| 连续输入大写 | 连续点 Shift 两次锁定大写，图标增加下划线；再点一次恢复小写；点一次仍只让下一个字母大写 |
| 中 / 英切换 | `中文` / `EN`；选择会保存，密码、邮箱等输入框临时使用英文 |
| 切换到其他输入法 | 长按 `空格`；Android 8 上打开系统输入法选择器 |
| 输入标点 | 所有模式统一使用英文半角标点；文字键盘的 `,` 与 `.` 可直接输入 |
| 输入数字 | `123` 进入九宫格数字页，`0` 位于底行；数字输入框自动打开数字页 |
| 输入符号 | `符号` 图标或拼音 1 键进入英文符号页，`下一页` / `上一页` 切换；`拼音`、`ABC` 或 `返回数字` 返回之前的键盘 |
| 剪贴板 | 工具栏的剪贴板图标，点击条目粘贴；支持固定、删除与清空 |
| 全选 | 同一工具栏的全选图标，随后点击退格图标可以删除全部文字 |
| 编辑工具 | 同一工具栏的铅笔图标；提供复制、剪切、粘贴、全选、左右移动及开头 / 末尾；操作前提交正在输入的候选 |
| 打开密码管理器 | 同一工具栏的钥匙图标打开已安装的 Bitwarden；未安装时提示并保持当前输入 |
| 打开双因素应用 | 同一工具栏的盾牌时钟图标打开已安装的 Google 验证器；未安装时提示并保持当前输入 |
| 键盘高度 | `编辑` → `设置` → `矮` / `标准` / `高`；选择会保存，返回后保留之前的数字或文字键盘 |
| 键盘主题 | `编辑` → `设置` → `跟随系统` / `浅色` / `深色`；默认跟随系统，选择会保存 |
| 前后鼻音 | 铅笔图标 → `设置` → `an/ang` / `en/eng` / `in/ing`；独立开启，默认关闭，作用于拼音九键 |
| 收起键盘 | 工具栏最右侧向下箭头；拼音、数字、符号、展开候选和剪贴板页均可使用 |

候选栏可横向滑动，也可展开为多列。中文在上、英语释义在下；过长释义会省略，长按查看释义提示，没有收录的显示「暂无释义」。长按提示受系统行数限制。输入变化后候选栏从第一项显示。
仅有拼音九键、英语全键盘、数字九键三种输入模式；符号页是临时面板。切换到数字页先提交正在输入的拼音。
拼音九键底行中间依次为 `123`、`空格`、`EN`，各占一个键位；数字与英语模式按钮分别位于空格的左右。
顶部固定一行，空闲显示工具；输入时原位显示候选与英语释义，工具只保留收起。候选显示或隐藏时键盘高度和按键位置保持不动。
九宫格的 1–9 位于各按键中心，下方字母是拼音提示。输入时左侧一栏显示独立的可滚动拼音组合，点击选项缩小候选范围；英语全键盘退格键宽于普通字母键。
工具栏从左到右为全选、编辑、Google 验证器、Bitwarden 密码管理器、剪贴板、收起。圆形底上的图标居中，按钮固定宽度、靠右排列；长按显示名称，辅助功能仍能读出名称。回车保留发送、搜索、完成等实际动作名称。
英语全键盘空格居中，左侧紧邻 `123`、右侧紧邻 `中文`；锁定大写在临时数字、符号面板返回后保持，切换输入语言后恢复小写。
数字底行中央为 `EN | 0 | 拼音`，空格移到左侧功能键位。0 与 2 / 5 / 8 保持同一中线。
钥匙图标优先打开 Bitwarden 保险库，之后点击搜索；手机上的 2026.9.0 未提供外部搜索页入口。盾牌时钟图标打开 Google 验证器；未安装时保留拼音并提示。
展开候选时也可以长按退格连续删除，候选刷新不会打断长按；松手或手指滑出删除键后停止。
应用重新初始化同一文本框时，未改变的拼音可继续选词；应用更改正文、输入类型或隐私属性时重新判断，避免旧候选覆盖新内容。
每次未上屏的拼音最多 64 个按键；达到上限时显示提示，选词或删除后可以继续。
点击收起键盘会先提交正在输入的第一候选，再隐藏键盘。
剪贴板历史保存在本机，最多 30 条；未固定内容在 24 小时后过期。密码框只提供当前复制内容的即时粘贴，不展示或记录历史。
键盘隐藏期间受系统限制，无法保证记录每次复制；重新打开时可以获取当前复制内容。
当前复制与相同的历史只显示一条，仍可固定或删除。删除当前复制的历史条目会同时删除系统剪贴板中的该段文字。
关闭剪贴板或粘贴后返回之前的文字或数字键盘，小数点、正负号及电话符号保持可用。
当前版本没有滑动输入和语音输入。
安装与启用步骤见 [Android](android.md)。
